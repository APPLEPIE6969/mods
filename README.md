# Drugs Mod for Minecraft 1.20.1 - 1.21.11

A comprehensive Minecraft mod that adds realistic drugs, smokable items, and crafting systems with proper chemical synthesis and dangerous combination effects.

## 🌿 Features

### **50+ Drug Items**
- **Stimulants**: Amphetamine, Speed, Cocaine, Crack, Methamphetamine, Ecstasy/MDMA/Molly
- **Depressants**: Benzodiazepines (Xanax, Diazepam, etc.), Opiates (Heroin, Morphine, Fentanyl, etc.), GHB variants
- **Psychedelics**: Cannabis, LSD, Magic Mushrooms, Ketamine, Salvia, DMT, Mescaline
- **Solvents**: Glue, Aerosol, Nitrous Oxide, etc.
- **Synthetic Opioids**: Nitazenes (extremely potent)
- **Natural Plants**: Coca leaves, Opium poppies, Magic mushrooms, Peyote cactus, etc.

### **🧪 Specialized Crafting System**
- **Chemistry Lab Table**: Meth synthesis, LSD synthesis
- **Drug Processing Table**: Cocaine extraction, Heroin processing, Crack making
- **Extraction Table**: DMT extraction, Mescaline extraction, Kratom extract
- **Synthesis Table**: Ecstasy synthesis, Fentanyl synthesis, GHB synthesis

### **⚗️ Realistic Effects & Dangers**
- **Proper drug effects** with accurate durations and intensities
- **Dangerous combinations** that can be fatal:
  - Stimulant + Stimulant = Serotonin Syndrome
  - Cocaine + Alcohol = Cocaethylene (heart damage)
  - Depressant + Depressant = Respiratory failure
  - Multi-drug combos = Psychosis, enhanced overdose risk
- **Warning system** for dangerous combinations
- **Overdose mechanics** with health loss
- **Withdrawal effects**: Anxiety, paranoia, psychosis

### **🌍 World Generation**
- Natural drug plants spawn in appropriate biomes:
  - Jungle: Coca leaves, Kratom leaves, Kava roots
  - Desert: Ephedra, Peyote cactus
  - Plains: Opium poppies
  - Dark Forest: Magic mushrooms
  - Mountains: Salvia divinorum

### **📦 Ingredient Acquisition**
- **World generation**: Natural plants and minerals
- **Loot tables**: Find chemicals and equipment in various structures
- **Crafting**: Lab equipment and processing tools

## 🚨 Content Warning
This mod contains mature themes including drug use, addiction, and overdose. It is intended for mature audiences only and should not be used by minors.

## 📋 Requirements
- **Minecraft**: 1.20.1 - 1.21.11
- **Forge**: 47.2.0 or higher
- **Java**: 17 or higher

## 📦 Installation
1. Install Forge for your Minecraft version
2. Download the mod JAR file
3. Place the JAR in your `mods` folder
4. Launch Minecraft with Forge

## 🎮 Getting Started
1. **Gather ingredients** from world generation or loot chests
2. **Craft specialized tables** for drug synthesis
3. **Follow recipes** to create various substances
4. **Be careful with combinations** - mixing drugs can be dangerous!
5. **Use Naloxone** to reverse opioid overdoses

## 🔧 Crafting Examples

### Meth Synthesis (Chemistry Lab Table)
```
Pseudoephedrine + Red Phosphorus + Iodine + Anhydrous Ammonia → Meth
```

### Cocaine Extraction (Drug Processing Table)
```
Coca Leaf + Sulfuric Acid + Kerosene → Cocaine
```

### LSD Synthesis (Chemistry Lab Table)
```
Morning Glory Seeds + Lithium + Sulfuric Acid → LSD
```

## ⚠️ Dangerous Combinations
- **Cocaine + Alcohol**: Forms cocaethylene (highly toxic)
- **Heroin + Alcohol**: Respiratory depression and overdose
- **Meth + MDMA**: Serotonin syndrome (potentially fatal)
- **Multiple stimulants**: Heart failure risk
- **Multiple depressants**: Complete respiratory failure
